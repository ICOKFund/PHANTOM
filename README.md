# PHANTOM

코스닥 제조업 기업이 3년 안에 한계기업이 될 위험을 조회하는 사이트입니다. 광운대학교 참빛설계학기 연구팀의 로지스틱 회귀 모형(2013~2022년 코스닥 제조업 995개사, 6,633 기업-연도)으로 계산했습니다.

- 대상: 코스닥 제조업 1,187개사(2013~2024년, 상장폐지 기업 포함)
- 기준: 2024년 결산 공시
- 자료: DataGuide(재무·이자상환 상태), DART 전자공시(메자닌·최대주주·요약재무제표), 사업보고서 주석 원문 판독(정책금융), 한국거래소(상장폐지)

등급은 3년 안 한계기업 진입 위험의 순서를 매기는 연구용 추정치이며, 투자 권유나 신용평가가 아닙니다.
